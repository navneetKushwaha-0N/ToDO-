# 📝 To-Do App

A simple and responsive To-Do application built to practice and revise core JavaScript concepts such as CRUD operations, functions, DOM manipulation, and event handling.

---

# 🚀 Purpose of This Project

This project was created for revision and hands-on practice of:

- CRUD Operations
- JavaScript Functions
- DOM Manipulation
- Event Handling
- Local Storage
- Frontend Development Basics

---

# ✨ Features

- ➕ Add Tasks
- 📖 Read/View Tasks
- ✏️ Update/Edit Tasks
- ❌ Delete Tasks
- 💾 Save Tasks using Local Storage
- 📱 Responsive Design

---

# 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)

---

# 📚 Concepts Practiced

## CRUD Operations

| Operation | Description |
|----------|-------------|
| Create | Add new task |
| Read | Display tasks |
| Update | Edit existing task |
| Delete | Remove task |
